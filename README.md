# CAD-PROJECTS

This repository showcases my CAD, BIM, and computational design work.  
It includes parametric models, structural detailing, and automation scripts that demonstrate my ability to transform engineering concepts into construction-ready documentation.

## 🔧 Tools & Technologies
- **AutoCAD** – 2D drafting and detailing
- **Revit (Structure)** – BIM modeling and coordination
- **Navisworks** – Clash detection and integrated design delivery
- **OpenSCAD** – Computational modeling and parametric design
- **SQL & System Design** – Technical system implementation and data workflows

## 📐 Project Highlights
- Reinforced concrete detailing (rebar layouts, hooks, laps)
- Structural steel connections and general arrangement drawings
- Parametric building models in OpenSCAD
- Clash detection reports integrating structural, MEP, and architectural models
- Quantity take-offs (BOQ) extracted directly from BIM models
